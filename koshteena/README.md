### طريقة الإدارة
- **تحديث تطبيق الأندرويد:** أي تعديل يتدفع على GitHub داخل مجلد `koshteena/`، و GitHub Actions بيبني APK جديد براهو وبينشره على نفس الرابط.
- **تحديث موقع الويب:** الموقع على Vercel بيقرا الملفات من GitHub عبر jsDelivr، ومثبّت على commit محدد. بعد أي تعديل لازم تتعمل نشرة جديدة على الـ commit الجديد (اطلب من Claude ينشرها).
- **الإعدادات:** حد الحريق وأول نزول ووقت الدور بيتغيروا من داخل الغرفة. القيم الافتراضية في `shared/engine.js`.
- **خادم خاص (اختياري):** `npm start` بيشغّل خادم WebSocket وجدول ترتيب عام. اكتب عنوانه في إعدادات التطبيق ← "خادم خاص".

---

تطبيق موبايل للعب **الحريق** السوداني: أونلاين مع الأصحاب، أو ضد الكمبيوتر، بواجهة عربية كاملة (RTL) وهوية سودانية عصرية.

## ✨ المزايا

| الميزة | التفاصيل |

| 🏆 نقاط وترتيب | جدول ترتيب أونلاين في الخادم، وإحصائياتك ضد الكمبيوتر محفوظة في الجهاز |

| ⚡ سرعة اللعب | 💡 اقتراح أحسن تشكيلات، دبل تاب للرمي، ترتيب اليد، مؤقت للدور أونلاين، والكمبيوتر بيلعب بدل المنقطع |

## 🚀 التشغيل

```bash
cd koshteena
npm install
npm start            # http://localhost:8080
npm test             # اختبارات القواعد + محاكاة مباريات كاملة بين البوتات
```

افتح الرابط من الموبايل (نفس الشبكة) أو انشر الخادم على أي استضافة Node (Render وRailway وFly.io وغيرها). المتغيرات: `PORT` و`DATA_DIR` (مكان ملف الترتيب).

## 📱 بناء تطبيق أندرويد / آيفون

التطبيق PWA جاهز للتثبيت من المتصفح ("أضف للشاشة الرئيسية"). ولبناء تطبيق للمتاجر بـ Capacitor:

```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/android @capacitor/ios
npm run cap:android   # أو cap:ios (يحتاج Xcode على ماك)
```

بعد التثبيت ادخل **الإعدادات ← عنوان الخادم** واكتب عنوان خادمك (مثلاً `https://koshteena.example.com`) عشان اللعب الأونلاين يشتغل. اللعب ضد الكمبيوتر ما محتاج خادم.

## 🧱 البنية

```
koshteena/
├── shared/            # نفس الكود في الخادم والمتصفح
│   ├── engine.js      # الورق، التحقق من السيري/البنت، الجولة، الحساب
│   ├── ai.js          # البوت: بحث أمثل عن التشكيلات + السحب/الرمي/التلزيق
│   └── match.js       # الغرفة: مقاعد، جولات، حريق، دردشة، مؤقت، إعادة
├── server/index.js    # HTTP + WebSocket + /api/leaderboard
├── public/            # الواجهة (HTML/CSS/JS بدون أي build)
│   ├── app.js  cards.js  net.js  sound.js  style.css
│   └── manifest.webmanifest  sw.js  icon.svg
├── scripts/build-www.js
└── test/engine.test.js
```

- **وضع الكمبيوتر** بيشغّل نفس كلاس `Room` جوة المتصفح، فالقواعد مطابقة للأونلاين 100%.
- **البروتوكول**: العميل يرسل `hello / create / join / act / chat / emoji / ready / rematch`، والخادم يرد بـ `state` (عرض خاص بكل لاعب، وورق الباقين مخفي) و`chat` و`error`.

## 📜 القواعد المطبّقة (قابلة للتعديل في `DEFAULT_SETTINGS`)

- كوتشينتين + 4 جوكر = 108 ورقة. كل لاعب 14 ورقة والبادي 15 ويبدأ بالرمي.
- **السيري**: 3+ متتالية من نفس الشكل. الآص تحت (A23) أو فوق (QKA) بدون لف.
- **البنت**: 3–4 من نفس الرقم بأشكال مختلفة.
- الجوكرات في أي تشكيلة لازم تكون أقل من الورق العادي.
- **أول نزول** ≥ 51 (41 / 51 / 71 من الإعدادات). القيم: 2–9 بقيمتها، 10/J/Q/K = 10، الآص 11 (أو 1 في A23).
- **ورقة الأرض**: لازم تُستعمل في نفس الدور، أو ترجع وتسحب من الكومة.
- **التلزيق وتبديل الجوكر** مسموحين بعد ما تنزل.
- لازم تقفل برمي آخر ورقة.
- **الحساب**: الفائز 0، الباقين قيمة يدهم (الجوكر 25، الآص 11، الصور 10)، واللي ما نزل 100.
- **الحريق 🔥**: لو نزل لأول مرة وقفل في نفس الدور، العقوبات بتتضاعف.
- اللي بيوصل حد الحريق (151 / 201 / 251 / 351) بيطلع، وآخر واحد بيفضل هو البطل.

> قواعد الحريق بتختلف شوية من بيت لبيت ومن منطقة لمنطقة. كل الأرقام دي متغيرة في `shared/engine.js` و`shared/match.js`.

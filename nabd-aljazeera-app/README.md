# تطبيق صحيفة «نبض الجزيرة» – أندرويد

تطبيق أخبار عربي (من اليمين لليسار) لصحيفة نبض الجزيرة – ولاية الجزيرة، السودان.
مبني بـ Capacitor ويقرأ الأخبار تلقائياً من قاعدة بيانات الصحيفة (Supabase) – نفس قاعدة بيانات موقع الصحيفة ولوحة التحكم في `../nabd-aljazeera-site`.

## المميزات
- الأخبار حسب الأقسام، وشريط «عاجل»، وبحث، وتحميل المزيد، والسحب للتحديث.
- صفحة الخبر: تكبير الخط، والحفظ للقراءة دون إنترنت، والمشاركة عبر واتساب وفيسبوك.
- يعمل دون إنترنت بآخر أخبار محفوظة.
- وضع ليلي تلقائي، وزر الرجوع في أندرويد يعمل بشكل طبيعي.
- لا يجمع أي بيانات شخصية، ولا يطلب أي صلاحيات غير الإنترنت.

## ربط التطبيق بقاعدة بيانات الصحيفة (أهم خطوة)
1. جهّز موقع الصحيفة وقاعدة بياناته كما في `../nabd-aljazeera-site/README.md`.
2. افتح `www/config.js` وضع نفس القيم الموجودة في `config.js` الخاص بالموقع:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_KEY: "المفتاح العام (publishable / anon)",
   SITE_URL: "https://nabd-aljazeera.vercel.app",
   ```
   وعدّل البريد ورقم الواتساب ورابط سياسة الخصوصية.
3. أعد بناء التطبيق (انظر أدناه) وارفع الإصدار الجديد.

بعدها أي خبر ينشره المحرر من لوحة التحكم (`/admin`) يظهر في التطبيق والموقع فوراً دون تحديث التطبيق.

## البناء
المتطلبات: Node.js 22، وJava 21، وAndroid SDK (platform 36، build-tools 36).

```bash
npm install
npx cap sync android
cd android
./gradlew bundleRelease    # ملف Play Store: app/build/outputs/bundle/release/app-release.aab
./gradlew assembleRelease  # ملف تجربة على الجوال: app/build/outputs/apk/release/app-release.apk
```

عند كل إصدار جديد ارفع `versionCode` (رقم صحيح) و`versionName` في `android/app/build.gradle`.

## مفتاح التوقيع ⚠️
التوقيع يُقرأ من مجلد `signing/` (غير مرفوع إلى GitHub عمداً):
- `signing/nabd-upload.jks` – مفتاح الرفع (Upload key)
- `signing/keystore.properties` – كلمة المرور

احتفظ بنسخة منهما في مكان آمن (فلاش + بريد خاص). كل التحديثات القادمة يجب أن تُوقَّع بنفس المفتاح.
مع تفعيل «Play App Signing» يمكن لجوجل إعادة تعيين مفتاح الرفع إذا فُقد.

## مجلد `store-listing/`

(استبدل لقطات الشاشة بلقطات حقيقية بعد ربط الموقع). النصوص في `store-listing/listing.md`.

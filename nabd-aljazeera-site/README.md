# موقع صحيفة «نبض الجزيرة» + لوحة التحكم

- **الموقع العام** (`public/`): الرئيسية، الأقسام، البحث، صفحة الخبر، من نحن، سياسة الخصوصية.
- **لوحة التحكم** (`public/admin/`): دخول المحررين، كتابة الأخبار وتعديلها وحذفها، رفع الصور (تُصغَّر تلقائياً)،
  عاجل/رئيسي/مسودة/نشر مجدول، وإدارة المحررين.
- **قاعدة البيانات** (`supabase/schema.sql`): Supabase (Postgres + تسجيل الدخول + تخزين الصور) بسياسات أمان:
  القارئ يرى المنشور فقط، والمحرر ينشر، والمدير وحده يضيف المحررين.

نفس قاعدة البيانات يقرأ منها تطبيق أندرويد في `../nabd-aljazeera-app`.

## خطوات التشغيل (مرة واحدة – حوالي 10 دقائق)

### 1) قاعدة البيانات على Supabase (مجاني)
1. ادخل [supabase.com](https://supabase.com) ← **New project** ← الاسم `nabd-aljazeera`، المنطقة **Frankfurt (eu-central-1)**، واختر كلمة مرور قوية واحفظها.
2. بعد اكتمال الإنشاء: **SQL Editor** ← الصق محتوى `supabase/schema.sql`
   - **غيّر** `admin@example.com` في آخر الملف إلى بريد مدير الموقع.
   - اضغط **Run**.
3. **Authentication ← URL Configuration**:
   - Site URL: رابط الموقع (مثل `https://nabd-aljazeera.vercel.app`)
   - Redirect URLs: أضف `https://nabd-aljazeera.vercel.app/admin/`
4. **Project Settings ← API**: انسخ **Project URL** و**المفتاح العام** (publishable أو anon).
   هذان آمنان للنشر. ⚠️ لا تستخدم مفتاح `service_role` أبداً.

### 2) الإعدادات
ضع القيمتين في `public/config.js` (وفي `www/config.js` بالتطبيق)، مع البريد ورقم الواتساب.

### 3) النشر على Vercel (مجاني)
- اربط المستودع في Vercel واختر مجلد الجذر `nabd-aljazeera-site/public` دون أي أمر بناء (موقع ثابت)،
- أو من الطرفية: `cd public && npx vercel --prod`.

### 4) أول دخول
افتح `/admin/` ← «إنشاء حساب جديد» بالبريد الذي وضعته في الخطوة 1 ← أكّد البريد من الرسالة ← سجّل الدخول وابدأ النشر.
لإضافة محرر: تبويب «المحررون» ← أضف بريده ← يفتح هو `/admin/` وينشئ حساباً بنفس البريد.

## ملاحظات
- الخطة المجانية في Supabase توقف المشروع مؤقتاً إذا لم يُستخدم أسبوعاً كاملاً؛ موقع أخبار نشط لا يتأثر.
- رسائل تأكيد البريد المجانية من Supabase محدودة العدد في الساعة؛ لعدد كبير من المحررين اربط خدمة بريد (SMTP) من إعدادات Authentication.
- لربط نطاق خاص (مثل `nabdaljazeera.com`): Vercel ← Project ← Domains.
- تم اختبار ملف قاعدة البيانات على PostgreSQL 16 محلياً: يعمل ويمكن إعادة تشغيله بأمان، وسياسات الأمان مختبرة لكل دور (قارئ، مستخدم غريب، محرر، مدير).

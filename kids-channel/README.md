# بُستان القِيَم ⭐ — قناة تعليمية للأطفال

قيمٌ وأخلاقٌ إسلاميّة لكلّ العائلة، بأسلوب حكايات مرحة. مقدّمة القناة **نور** — نجمة صغيرة ضاحكة.
إعداد: **د. الفاضل بلال**

## ما في هذا المجلد

| المجلد | المحتوى | المقاس |
|---|---|---|
| `brand/logo.png` | الشعار الكامل | 1000×1000 |
| `brand/avatar.png` | صورة القناة (يوتيوب يقصّها دائرة) | 800×800 |
| `brand/banner.png` | غلاف يوتيوب (النص داخل المنطقة الآمنة) | 2560×1440 |
| `brand/thumbnail-ep01.png` | الصورة المصغّرة للحلقة ١ | 1280×720 |
| `posters/*.png` | ٣ بوسترات: صلة الرحم، الصدق، الابتسامة صدقة | 1080×1350 (إنستغرام/واتساب) |
| `episode-01/` | الحلقة الأولى: السيناريو + ٦ مشاهد مرسومة + فيديو تجريبي صامت | 1920×1080 |
| `content-plan.md` | خطة المحتوى: السلاسل، ١٢ حلقة بمصادرها، جدول النشر | — |

## الشخصيات
- **نور** ⭐ المقدّمة · **عُمَر** و**مريم** (أخ وأخت) · **الجدّة**

كلّ الرسومات مرسومة بالكود (SVG) في `assets/chars.js`، فيمكن إعادة استخدام الشخصيات في أي حلقة بتعابير مختلفة
(`happy` · `talk` · `sad` · `wink` · `closed`) وأغراض بأيديهم (`gift` · `phone` · `tablet`).

## إعادة توليد الصور
بعد تعديل أي ملف `.html`:

```bash
node kids-channel/render.js            # كل الصور
node kids-channel/render.js posters    # البوسترات فقط
```

يستخدم الخطوط الموجودة في `../poster/` (Cairo و Amiri).

## ⚠️ قبل النشر
النصوص الشرعية (الأحاديث والآيات) مكتوبة مع مصادرها، ويُستحسن مراجعتها مع طالب علم أو شيخ قبل النشر.
